Если появляется ошибка "Подключение не установлено" (2002):

1. Запустите MySQL/MariaDB в OSPanel
   - Откройте панель OSPanel (иконка в трее).
   - В списке модулей найдите MySQL или MariaDB (например MariaDB-10.4).
   - Включите сервер (должна появиться зелёная метка).
   - Запомните порт: Настройки → Модули → ваш MySQL — указан порт (часто 3306).

2. Проверьте порт в config.inc.php
   - В этом файле (config.inc.php) у первого сервера [1] указан порт 3306.
   - Если в OSPanel у вашего модуля другой порт — замените в config.inc.php:
     $cfg['Servers'][$i]['port'] = '3307';   // ваш порт

3. Хост 127.0.0.1
   - В config.inc.php для первого сервера стоит host = 127.0.0.1.
   - Сайт (config/database.php) берёт эти же параметры из phpMyAdmin — менять нужно только здесь.

4. После запуска MySQL откройте phpMyAdmin в браузере — если он открывается, сайт тоже должен подключиться.
