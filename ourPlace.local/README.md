## Our Place — документация проекта

### Общая информация

Проект — интернет‑магазин/витрина на PHP (classic LAMP‑стек: **PHP + MySQL + Apache/Nginx**), без фреймворков, с разделением на фронтенд (шаблоны, стили, JS) и бэкенд (PHP‑скрипты, работа с БД, отправка почты).

PHP‑зависимости ставятся через **Composer** (см. `composer.json`, папка `vendor`).

---

### Структура проекта

- **Корень проекта**
  - `index.php` — главная страница.
  - `catalog.php`, `product.php` — каталог и карточка товара.
  - `cart.php`, `add_to_cart.php`, `checkout.php`, `order_success.php`, `order_history.php`, `receipt_pdf.php` — корзина, оформление и история заказов, генерация чека.
  - `login.php`, `register.php`, `profile.php`, `logout.php` — авторизация, регистрация и профиль пользователя.
  - `site.html` — статичная версия/макет страницы.
  - `composer.json`, `composer.lock`, `composer.phar`, `install_composer.bat` — файлы Composer.

- **`admin/` — административная панель (back end)**
  - Скрипты управления товарами, заказами и т.п.
  - Доступ обычно только для администратора (через авторизацию).

- **`config/` — конфигурация (back end)**
  - `database.php` — параметры подключения к базе данных и инициализация `PDO`.
  - `email.php` / `email.example.php` — настройки SMTP и отправки почты (Gmail или другой SMTP‑сервер).

- **`includes/` — общие включаемые файлы (back/front)**
  - Общие функции, шаблоны шапки/подвала, подключение конфигурации и т.д., которые подключаются через `include`/`require`.

- **`lib/` — библиотечный код (back end)**
  - Вспомогательные классы и функции, логика отправки писем (`send_order_emails.php` и др.).

- **`css/` — стили (front end)**
  - CSS‑файлы для пользовательской и, при необходимости, админской части.

- **`js/` — JavaScript (front end)**
  - Скрипты для динамического поведения на клиенте (валидация форм, взаимодействие с корзиной и т.д.).

- **`images/` — статичные ресурсы (front end)**
  - Изображения товаров, логотипы, иконки и прочее.

- **`database/` — база данных**
  - `copy database/ourplace.sql` — дамп MySQL‑базы (`ourplace`) для развёртывания на хостинге.

- **`vendor/` — внешние PHP‑библиотеки**
  - Содержимое генерируется Composer’ом (`composer install`). Не редактируется вручную.

- **`.osp/`**
  - Служебные файлы OSPanel (локальное окружение, на боевой сервер обычно не нужны).

- **`phpmyadmin/`**
  - Локальный phpMyAdmin (часть OSPanel, на внешний хостинг обычно НЕ заливается).

- **`temp/`**
  - Временные файлы (кеш, временные выгрузки и т.п.). Можно чистить по необходимости.

---

### Фронтенд vs Бэкенд

- **Фронтенд**
  - HTML/PHP‑шаблоны в корне (`index.php`, `catalog.php`, `product.php`, и др.).
  - Статические ресурсы: `css/`, `js/`, `images/`.

- **Бэкенд**
  - Логика работы с БД и почтой: `config/`, `includes/`, `lib/`, большинство файлов в `admin/`, часть скриптов в корне (`checkout.php`, `add_to_cart.php` и др.).
  - Внешние библиотеки: `vendor/`.

---

### Требования к окружению

- **PHP**: рекомендуемая версия ≥ 8.0 (поддержка PDO, mbstring, intl желательны).
- **Web‑сервер**: Apache или Nginx.
- **MySQL/MariaDB**: поддержка InnoDB и UTF‑8/utf8mb4.
- **Доступ к консоли** (желательно) для запуска Composer.

### Развёртывание на хостинге (prod)

#### 1. Подготовка домена и корня сайта

- **Создайте домен/поддомен** в панели хостинга.
- В качестве **корня сайта** укажите папку, куда будет загружено содержимое текущего проекта (все файлы и папки из `ourPlace.local`).
- Убедитесь, что точкой входа является `index.php` (обычно по умолчанию).

#### 2. Загрузка файлов проекта

1. Скопируйте на хостинг все файлы и каталоги из проекта:
   - папки: `admin/`, `config/`, `css/`, `images/`, `includes/`, `js/`, `lib/`, `temp/`.
   - файлы в корне: `index.php`, `catalog.php`, `product.php`, `cart.php`, `add_to_cart.php`, `checkout.php`, `order_success.php`, `order_history.php`, `receipt_pdf.php`, `login.php`, `register.php`, `profile.php`, `logout.php`, `site.html`, `composer.json`, `composer.lock`.
2. **Не обязательно/не рекомендуется** переносить:
   - `.osp/`, `phpmyadmin/` — служебные каталоги локального OSPanel.
   - Локальные дампы БД можно хранить вне корня сайта, если хостинг это позволяет.

#### 3. Установка PHP‑зависимостей (Composer)

**Вариант A (предпочтительно, если есть SSH)**:

1. Подключитесь к серверу по SSH, перейдите в корень проекта.
2. Выполните:

   ```bash
   php composer.phar install --no-dev --optimize-autoloader
   ```

   или, если Composer установлен глобально:

   ```bash
   composer install --no-dev --optimize-autoloader
   ```

**Вариант B (если SSH недоступен)**:

1. Выполните `composer install` локально (на машине разработки), чтобы заполнить папку `vendor/`.
2. Загрузите уже сформированную папку `vendor/` на хостинг по FTP/файловому менеджеру.

#### 4. Создание и импорт базы данных

1. В панели хостинга создайте **новую базу данных** (например, `ourplace_prod`) и пользователя с паролем.
2. Запомните:
   - **host** (сервер БД, часто `localhost` или что‑то вроде `mysql.yourhost.com`);
   - **dbname** (имя БД);
   - **user** и **password**.
3. Импортируйте дамп:
   - через phpMyAdmin или аналог импортируйте файл `database/copy database/ourplace.sql` в созданную БД.

#### 5. Настройка подключения к БД

1. Откройте файл `config/database.php` на хостинге.
2. Замените параметры:

   ```php
   $dbHost = 'ВАШ_HOST';
   $dbName = 'ИМЯ_БД';
   $dbUser = 'ПОЛЬЗОВАТЕЛЬ_БД';
   $dbPass = 'ПАРОЛЬ_БД';
   ```

3. Сохраните файл и убедитесь, что сайт открывается без ошибок подключения к БД.

#### 6. Настройка отправки почты (SMTP)

1. **Не храните реальные пароли в репозитории.** Для боевого сервера используйте `config/email.php`, а в репозитории оставьте/используйте `email.example.php` как шаблон.
2. На хостинге:
   - Скопируйте `config/email.example.php` в `config/email.php` (если это ещё не сделано).
   - Заполните в `config/email.php` реальные SMTP‑данные (хост, порт, логин, пароль приложения, `from_email`, `from_name`).
3. Убедитесь, что хостинг **разрешает исходящие SMTP‑подключения** (иначе используйте встроенный почтовый сервис хостинга, если есть, и адаптируйте конфиг).

#### 7. Права на файлы и папки

- Установите права, рекомендованные хостингом.
- Как минимум:
  - PHP‑файлы: **644/640**.
  - Папки (особенно с временными файлами, если используются): **755/750**.
- Не давайте прав `777`, если в этом нет крайней необходимости.

#### 8. Проверка работы

- Откройте сайт в браузере по домену.
- Проверьте:
  - регистрацию и логин пользователя;
  - добавление товаров в корзину и оформление заказа;
  - отправку писем (подтверждение заказа и т.п.);
  - формирование PDF‑чека (если используется).

### Развёртывание на локальном окружении (OSPanel)

1. Скопируйте проект в папку домена OSPanel (например, `OSPanel/home/ourPlace.local`).
2. Убедитесь, что модуль MySQL запущен.
3. Через локальный phpMyAdmin импортируйте `database/copy database/ourplace.sql` в базу `ourplace` (или своё имя БД, не забудьте поменять его в `config/database.php`).
4. При необходимости настройте `config/email.php` для локальной отправки писем (можно использовать тестовую почту/Gmail с паролем приложения).
5. Откройте проект по адресу вида `http://ourPlace.local/` через OSPanel.

---

### Полезные замечания

- **Безопасность**
  - Не заливайте на хостинг лишние служебные файлы (локальный phpMyAdmin, отладочные скрипты, дампы БД в открытом доступе).
  - Закройте доступ к админке паролем и, по возможности, ограничьте IP.

- **Обновления**
  - При обновлении кода соблюдайте структуру проекта, не удаляйте папку `vendor/` без повторного запуска Composer.

- **Резервные копии**
  - Регулярно делайте бэкапы БД и важных пользовательских файлов (например, загруженных изображений товаров).
